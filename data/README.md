# Practice datasets

These datasets are **synthetic**: generated by a program for teaching, not taken from any real lender or real people. Patterns in them (for example, higher-risk loans being repaid less often) were built in on purpose so lessons have something real to discover. Don't use them to draw conclusions about real borrowers or regions.

## `loans.csv` — 500 small personal loans (clean)

Used from Lesson 1 onward.

| Column | Type | Description |
| --- | --- | --- |
| `loan_id` | text | Unique loan reference, `L0001`–`L0500` |
| `application_date` | date | Date the loan was applied for (2025) |
| `region` | category | Region of the applicant: Lagos, Abuja, Kano, Rivers, Oyo, Enugu |
| `age` | whole number | Applicant age in years |
| `employment` | category | Salaried, Self-employed or Business owner |
| `monthly_income_ngn` | whole number | Reported monthly income in Naira |
| `loan_amount_ngn` | whole number | Amount borrowed in Naira |
| `tenure_months` | whole number | Loan length: 3, 6, 12, 18 or 24 months |
| `previous_loans` | whole number | Number of earlier loans the applicant has had |
| `risk_band` | ordered category | Lender's risk rating at application: low, medium, high |
| `repaid` | yes / no | Whether the loan was repaid in full (the **target** in modelling lessons) |

## `loans_raw.csv` — the same loans, messy (503 rows)

Used in the data-cleaning lessons. It deliberately contains the problems real data has: missing incomes and employment values, inconsistent region labels, duplicated rows, and a couple of impossible values to find and fix.
