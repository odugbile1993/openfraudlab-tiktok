## In a nutshell

Python is a popular first language for data science because it is readable, free, and has strong libraries like pandas, NumPy, Matplotlib and scikit-learn. Code also makes your analysis repeatable.

## Key ideas

- **The question:** Spreadsheets get you far. Why code?
- **Readable:** Python reads almost like plain English — Friendly for beginners
- **Libraries:** pandas · NumPy · Matplotlib · scikit-learn — Tables · maths · charts · machine learning
- **Repeatable:** Code is a recipe you can rerun — New data next month? Run it again.
- **Free & supported:** Free, open source, huge community
- **Takeaway:** Python isn't the only option, but it's a strong first one

## Try it yourself

Think of one task you repeat in a spreadsheet every week or month. Write down, step by step in plain English, what you do — that list is the start of a script.

Data Science from Scratch, lesson fifteen: why Python for data science.

Spreadsheets can take you surprisingly far. So why do most data scientists learn to code, and why is Python such a common choice?

First, Python is known for being readable. Its code often looks close to plain English, which makes it a friendly first language.

Second, its libraries. pandas handles tables, NumPy handles fast maths on arrays, Matplotlib draws charts, and scikit-learn gives you many standard machine learning models.

Third, code is repeatable. A script is a recipe: when new data arrives next month, you run the same steps again, and anyone can check exactly what you did.

And Python is free and open source, with a large community, so when you get stuck, someone has usually asked the same question before.

So the takeaway: Python isn't the only option. R and SQL are useful too. But it's a strong first language for data science.
