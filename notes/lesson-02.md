## In a nutshell

Data is structured or unstructured; numerical data is discrete or continuous; categorical data is nominal or ordinal. The type decides which analysis makes sense.

## Key ideas

- **Why it matters:** The type of data decides what you can do with it.
- **Big split:** Structured vs unstructured — Tables with rows and columns · text, images, audio
- **Numerical:** Discrete: counted / Continuous: measured — Number of loans · a person's height
- **Categorical:** Nominal: no order / Ordinal: has an order — City, payment method · low, medium, high risk
- **Common mistake:** Averaging categories that are stored as numbers — If 1 = Lagos and 2 = Abuja, an 'average city' of 1.5 means nothing.
- **Takeaway:** Know your data type before you analyse.

## Try it yourself

List 6 columns you might find in a customer table (for example age, city, number of purchases, membership level). Label each as discrete, continuous, nominal or ordinal.

Data Science from Scratch, lesson two: the types of data, and why they matter.

Before you analyse anything, you need to know what kind of data you have. The type decides which charts, statistics, and models make sense.

First, the big split. Structured data fits neatly into tables, with rows and columns, like a spreadsheet. Unstructured data doesn't: think text, images, and audio.

Numerical data comes in two kinds. Discrete data is counted, like the number of loans someone has taken. Continuous data is measured, like a person's height, and can take any value in a range.

Categorical data puts things into groups. Nominal categories have no natural order, like city or payment method. Ordinal categories do have an order, like low, medium, and high risk.

A classic beginner mistake: treating categories as numbers just because they're stored as numbers. If one means Lagos and two means Abuja, an average city of one point five means nothing.

So the takeaway: always check your data types before you analyse.
